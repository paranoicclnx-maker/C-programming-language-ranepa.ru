Продолжаю разработку консольного конвертера единиц измерения длины на языке C.

- Добавил прототипы функций перед `main()`.
- Реализовал получение пользовательского выбора через функции.

## Изученные темы

- Прототипы функций.
- Типы возвращаемых значений `int` и `double`.
- Объявление и вызов пользовательских функций.

## Исправленные проблемы

В процессе разработки столкнулся с несколькими ошибками компиляции:

- `implicit-function-declaration` — вызов функции до её объявления.
- `conflicting types` — несоответствие типов функции и её объявления.

Разобрался с причиной ошибок и изучил роль прототипов функций.
